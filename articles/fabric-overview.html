Microsoft Fabric: the big picture

A beginner-friendly overview of Fabric workloads and OneLake.

FabricSafar · Beginner-friendly · Starter guide

Microsoft Fabric is an end-to-end analytics platform that brings data integration, engineering, warehousing, data science, real-time analytics and business intelligence experiences together.

Why does Fabric matter?

Data teams often use separate services to move, store, prepare and report on data. Fabric provides an integrated environment for these workloads, with shared experiences and governance capabilities.

Main workloads

  • Data Factory: data movement and orchestration.
  • Data Engineering: engineering and transformation experiences, including Spark.
  • Data Warehouse: analytical SQL warehousing.
  • Data Science: data science and machine learning workflows.
  • Real-Time Intelligence: streaming and event-driven data.
  • Power BI: modelling, visualisation and reporting.

What is OneLake?

OneLake is the unified logical data lake for an organisation in Fabric. It provides a common place to organise data across Fabric experiences.

Beginner learning order

  1. Learn workspaces and items.
  2. Understand OneLake and lakehouse concepts.
  3. Explore ingestion and transformation.
  4. Compare lakehouse and warehouse.
  5. Connect a semantic model and build a report.
